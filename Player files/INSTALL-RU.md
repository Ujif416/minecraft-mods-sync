# Установка клиентской сборки

1. Создайте отдельный профиль Minecraft 1.21.1 с NeoForge и Java 21. В последнем локальном журнале исходной сборки указан NeoForge 21.1.249; совместимость с работающим сервером отдельно не проверена.
2. Скачайте все моды из папки `Serwer mods` этого репозитория и положите в `mods` нового профиля. Дождитесь завершения первоначальной загрузки модов владельцем сборки. Папка `New mods` предназначена для новых, ещё не переведённых в серверный набор модов.
3. Скопируйте папки `config`, `defaultconfigs`, `kubejs` и `shaderpacks` из `Player files` в папку нового профиля Minecraft.
4. Скачайте файлы из `Player files/resourcepacks` в папку `resourcepacks` профиля. Включите необходимые ресурспаки в настройках игры.
5. Шейдеры включаются отдельно в настройках графики. Они необязательны для подключения; при низкой производительности отключите их.
6. Запустите игру и добавьте адрес сервера, полученный у администратора. Адрес и конкретный лаунчер пока не указаны.

Используйте новый профиль, чтобы старые моды и настройки не смешивались со сборкой. Сохранения, история серверов, личные данные и файлы авторизации не включены. Успешное подключение к серверу пока не проверено.

Репозиторий приватный: для скачивания игрокам нужен доступ к нему.
