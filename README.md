# Create Skybound — установка сборки для игроков

Клиентская сборка Minecraft для игры на сервере. Здесь находятся моды, настройки, ресурспаки и шейдеры.

> Адрес сервера получите у администратора. Инструкция подходит для лаунчера, который позволяет создать отдельный профиль с NeoForge и выбрать Java 21. Название лаунчера пока не задано.

## Версии

| Компонент | Версия |
| --- | --- |
| Minecraft | **1.21.1** |
| Загрузчик модов | **NeoForge** |
| NeoForge в журнале исходной сборки | **21.1.249** |
| Java | **21**, 64-разрядная |

Перед установкой уточните у администратора актуальную версию NeoForge на сервере. Forge и Fabric не заменяют NeoForge для этой сборки.

## 1. Скачать сборку

1. Войдите в GitHub под аккаунтом, которому выдан доступ к этому репозиторию. Репозиторий приватный; если видите 404, запросите доступ у администратора.
2. На главной странице репозитория выберите ветку **main**.
3. Нажмите **Code → Download ZIP** и дождитесь окончания скачивания.
4. Распакуйте архив. Откройте папку, внутри которой находятся `Serwer mods`, `Player files` и этот README.

Архив большой: только моды занимают около 1,08 ГБ. Для скачанного архива, распаковки и профиля понадобится дополнительное свободное место.

Игрокам **не нужны Python, скрипт sync_mods.py или токен GitHub**. Скрипт предназначен для владельца сборки.

## 2. Создать отдельный профиль

1. В своём лаунчере создайте **новый профиль Minecraft 1.21.1 с NeoForge**.
2. Выберите Java 21 в настройках этого профиля, если лаунчер не выбрал её автоматически.
3. Откройте **папку игры именно этого профиля** через лаунчер.
4. Закройте игру перед копированием файлов.

Не устанавливайте сборку поверх другой: старые моды и настройки могут вызвать конфликты.

## 3. Скопировать файлы

| Из скачанного репозитория | В папку профиля |
| --- | --- |
| Все файлы `.jar` из `Serwer mods` | `mods/` |
| `Player files/config` | `config/` |
| `Player files/defaultconfigs` | `defaultconfigs/` |
| `Player files/kubejs` | `kubejs/` |
| `Player files/resourcepacks` | `resourcepacks/` |
| `Player files/shaderpacks` | `shaderpacks/` |

**Копируйте содержимое `Serwer mods` в `mods`**, а не саму папку `Serwer mods`. Из `Player files` скопируйте пять перечисленных папок непосредственно в папку игры.

В результате должно получиться:

```text
Папка профиля/
├── mods/
│   ├── мод-1.jar
│   └── мод-2.jar
├── config/
├── defaultconfigs/
├── kubejs/
├── resourcepacks/
└── shaderpacks/
```

Не должно быть вложенности `mods/Serwer mods/` или `Папка профиля/Player files/config/`.

**Папку `New mods` не устанавливайте**, если администратор отдельно не попросил это сделать: она используется для новых модов до включения в серверный набор.

## 4. Первый запуск

1. Запустите подготовленный профиль и дождитесь главного меню. Первый запуск большой сборки может занять время.
2. В настройках ресурспаков включите нужные пакеты из списка доступных. Точный набор и порядок при необходимости уточните у администратора.
3. Шейдеры включайте отдельно в настройках графики. Они необязательны для подключения к серверу; при низком FPS отключите их.
4. Откройте **Сетевая игра → Добавить сервер**, введите адрес, полученный у администратора, и подключитесь.
5. Если на сервере используется список разрешённых игроков, заранее передайте администратору свой игровой ник.

## Если игра не запускается или сервер не пускает

- **Неверная версия / несовместимые моды:** проверьте Minecraft, NeoForge и соответствие набора модов серверу. Не добавляйте моды из `New mods` самостоятельно.
- **Duplicate mods / повторяющийся идентификатор мода:** в текущем исходном наборе обнаружены по две версии **Balm** и **Moonlight**. Если загрузчик сообщает о дубликатах, попросите администратора указать, какую версию оставить для сервера; не выбирайте наугад.
- **Не хватает зависимостей:** проверьте, что все `.jar` скопированы прямо в `mods`, архив полностью скачан и распакован.
- **Низкий FPS:** сначала отключите шейдеры и уменьшите дальность прорисовки.
- **Ошибка подключения:** проверьте адрес, доступность сервера и наличие вашего ника в списке разрешённых игроков, если он включён.
- **Вылет:** отправьте администратору текст ошибки и файл `logs/latest.log` из папки профиля, а при наличии — последний отчёт из `crash-reports`. Перед отправкой проверьте, что в них нет личных данных или токенов.

## Обновление сборки

Обновляйтесь по объявлению администратора. Закройте игру, сохраните копию текущего профиля и установите обновлённый набор в новый профиль либо следуйте инструкции администратора. Простое копирование новых модов поверх старых может оставить две версии одного мода.

## Состояние публикации

На **12 ноября 2026 года** в `Serwer mods` загружены **395 файлов .jar**: имена и размеры совпадают с локальным исходным набором. Папки для игроков, ресурспаки и шейдеры также опубликованы.

Это проверка полноты загрузки. Запуск чистой установки и успешное подключение к серверу пока не проверены; наличие всех файлов не подтверждает совместимость сборки.

---

### Для администратора

`sync_mods.py` предназначен для публикации модов, а не для установки игры. В текущей реализации обычный запуск добавляет новые файлы в `New mods` и переносит записи старше 7 дней в `Serwer mods`; `--init` загружает локальные файлы сразу в `Serwer mods`. Автоматическое расписание нужно настраивать отдельно. Папки игроков этим скриптом не синхронизируются.

Не публикуйте токены, сохранения, историю серверов и личные файлы. Перед объявлением новой версии проверьте сборку в чистом профиле и подключение к серверу.
